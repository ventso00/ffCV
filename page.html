      Bien jouer.
      Bien comprendre.

      Pourquoi mon ID ne charge pas encore automatiquement ? +

      La source étudiée répond bien, mais demande une clé d’accès serveur. Sans cette clé, la recherche ne peut pas fournir de données. Seule la démonstration reste visible en attendant l’activation de la source. Le panneau « État du service » indique la configuration réellement disponible.

      Est-ce mon personnage exact ? +

      Une image liée à ton compte nécessite un service de rendu de tenue compatible avec ton serveur. Sans source fiable, le personnage reste indisponible. Le concept de Bob est uniquement une illustration du studio, jamais présenté comme le personnage d’un UID saisi.

      Mon CV est-il vérifié ? +

      Le CV affiche les données reçues de la source en lecture seule. Un UID public ne prouve pas la propriété du compte. Aucune modification des statistiques n’est proposée. Aucun badge officiel Garena n’est attribué.

      Pourquoi mon profil est-il verrouillé ? +

      Le pseudo, le serveur et les statistiques sont récupérés par le programme. Pour actualiser ton CV, relance la recherche : aucune saisie personnelle ne remplace ces valeurs. La palette, le format et le fond graphique restent personnalisables.

      Comment installer sur Android ? +

      Utilise le bouton Installer ou le menu Chrome « Ajouter à l’écran d’accueil ». Cette version est une PWA. Le studio peut être utilisé hors connexion après chargement ; l’import UID nécessite internet. Aucun APK signé n’est encore distribué.
